## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина с главной страницей, каталогом, карточкой товара, формой заявки и контактами.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница карточки товара;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Страницы сайта

- `index.html` — hero-блок, преимущества, популярные товары, отзывы;
- `catalog.html` — каталог товаров, фильтры, сетка карточек;
- `product.html` — изображение товара, описание, характеристики, отзывы;
- `order.html` — форма заявки, кнопки состояний, таблица сравнения тарифов;
- `contacts.html` — контакты и ссылка на форму обратной связи.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `advantages` — список преимуществ;
- `contacts-list` — список контактов;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `reviews-grid` — сетка отзывов;
- `review-card` — карточка отзыва;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters-form` — форма фильтров;
- `product-detail` — страница карточки товара;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `data-table` — таблица характеристик или сравнения;
- `button` — кнопка;
- `badge` — бейдж;
- `scroll-top-button` — кнопка «Наверх»;
- `success-message` — сообщение об успешной отправке;
- `site-footer` — подвал сайта.

## БЭМ-модификаторы

В проекте используются модификаторы для вариантов компонентов:

- `site-nav__link--active` — активный пункт навигации;
- `product-card--featured` — выделенная карточка товара;
- `product-card--new` — новая карточка товара;
- `product-card--discount` — карточка товара со скидкой;
- `product-card--unavailable` — недоступный товар;
- `product-card__badge--sale` — бейдж скидки;
- `product-card__badge--new` — бейдж новинки;
- `button--primary` — основная кнопка;
- `button--secondary` — второстепенная кнопка;
- `button--danger` — кнопка опасного действия;
- `button--ghost` — прозрачная кнопка;
- `scroll-top-button--visible` — видимая кнопка «Наверх».

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров;
- CSS Grid для блока отзывов;
- CSS Grid для страницы товара и формы заявки.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:active`, `:disabled`, `:focus-within`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Позиционирование

В проекте используются:

- `position: relative` — для карточки товара как контейнера;
- `position: absolute` — для бейджей на карточках;
- `position: fixed` — для кнопки «Наверх»;
- `z-index` — для отображения фиксированной кнопки поверх контента.

## Изображения

В проекте используется папка `images/`.

Изображения подключаются через тег `<img>` с атрибутами:

- `src`;
- `alt`;
- `width`;
- `height`;
- `loading="lazy"`.

В CSS используется `object-fit: cover`, чтобы изображения корректно вписывались в карточки и миниатюры.

## Таблицы

В проекте используются таблицы:

- таблица характеристик товара на странице `product.html`;
- таблица сравнения тарифов доставки на странице `order.html`.
